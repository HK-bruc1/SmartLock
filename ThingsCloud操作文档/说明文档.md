## 使用MQTT.fx模拟接入测试

![image-20250218104025797](./说明文档.assets/image-20250218104025797.png)

### 打开MQTT.fx接入

点击蓝色齿轮，进入设置：去复制对应凭证即可。其他不用修改。

使用 MQTT.fx [官网open in new window](https://mqttfx.jensd.de/) 来模拟设备端与 ThingsCloud 建立 MQTT 连接以及上报数据。

这里采用 MQTT 普通认证方式，通过 username/password 完成连接身份验证。同样要用到之前拿到的设备证书，身份信息对应关系如下：

| 参数     | 值                                           |
| -------- | -------------------------------------------- |
| username | `AccessToken`                                |
| password | `ProjectKey`                                 |
| clientId | 任意（点击生成，后面发AT指令参数也需要这个） |

在 MQTT.fx 中设置连接参数，如下图：

![image-20250218104221662](./说明文档.assets/image-20250218104221662.png)

保存后，点击connect，右上角的指示灯成为绿色，代表连接上。可以使用这个模拟实现消息的上报和订阅。

![image-20250218104634187](./说明文档.assets/image-20250218104634187.png)

![image-20250218104700059](./说明文档.assets/image-20250218104700059.png)

### 实现消息上报

连接成功后，在 **Publish** 中填写发布到的主题 `attributes`，这个主题是 ThingsCloud 标准协议的属性上报主题。

然后在内容区中填写以下 `JSON` 消息：**AT指令上报时也是这种消息格式**

```
{
    "lock_status": 1
}
```

填入刚才创建设备类型时（指令）设置的标识和对应的值，点击上报即可，通过值的不同，可以去控制台观察是否上报成功

![image-20250218105442652](./说明文档.assets/image-20250218105442652.png)

![image-20250218105504150](./说明文档.assets/image-20250218105504150.png)

### 订阅消息

订阅消息是固定格式的，`attributes/push`，然后点击`Subscrlibe`。出现左边出现横条时，代表订阅成功。

直接去控制台点击属性的开和关实现消息（属性）的下发。就能在右下角看到`JSON`格式的消息了。

这也是ESP32回送MQTT消息时的格式。

![image-20250218105644133](./说明文档.assets/image-20250218105644133.png)

## 生成APP

回到控制台的设备类型：
![image-20250218110259660](./说明文档.assets/image-20250218110259660.png)

### 打开编辑器设计APP

为对应的组件绑定对应的指令（属性），右上角。自己选择合适的开关图标。
无论什么图标，`ON`对应的都是刚开始设置的设备类型（指令）的值`1`，`OFF`则是`0`。

![image-20250218110831048](./说明文档.assets/image-20250218110831048.png)

![image-20250218110514472](./说明文档.assets/image-20250218110514472.png)

### 用户添加设备

保存后，回到控制台的设备类型：
![image-20250218110259660](./说明文档.assets/image-20250218110259660.png)

点击**用户添加设备**

- 允许用户添加这个设备
- 把WiFi名称写上（**ESP32连接的WiFi名称**）
- 其他配置照着配置即可。

![image-20250218111046239](./说明文档.assets/image-20250218111046239.png)

### 创建用户并关联到设备

![image-20250218111517931](./说明文档.assets/image-20250218111517931.png)

**点击用户**->添加关联用户->创建新用户:

只需要填写

- 用户名称
- 登录名
- 密码
- 其他不用填写

**登录名和密码是登录APP的账号和密码**

![image-20250218111730094](./说明文档.assets/image-20250218111730094.png)

再点击关联用户时，就出现了刚才创建的用户了，点击关联即可。

![image-20250218112037864](./说明文档.assets/image-20250218112037864.png)

### 下载APP

关联后，回到控制台的设备类型：
![image-20250218110259660](./说明文档.assets/image-20250218110259660.png)

**进入管理APP**  ->  点击创建一个应用  ->  选择通用版

![image-20250218112313616](./说明文档.assets/image-20250218112313616.png)

![image-20250218112624770](./说明文档.assets/image-20250218112624770.png)

**此处的APPID也是登录APP的凭证之一。**

点击进入应用名称下的蓝色设备名称（**ESP32智能锁**）：


![image-20250218112640407](./说明文档.assets/image-20250218112640407.png)

## 下载“公版”对应的APP

使用**APPID，账号，密码**进行登录。

可以使用的前提是有设备通过WiFi以及MQTT协议连接着云平台的服务器。否则无法上报以及订阅信息

如果没有ESP32连接的话，可以使用MQTT.fx作为设备连接。也可以实现消息的上报和下发。可以去控制台查看效果。
